# M1 사건 단위 측정 — 사건 재현율 · 시간당 오탐 · K-of-N (2026-09-17)

지금까지(`M1_HANDOFF.md`, `M1_NODE_DROPOUT.md`)의 수치는 전부 **창 단위**였다.
여기서는 200 ms 간격으로 추론하는 시스템을 검증 세션 위에서 모사해 **사건(낙상 1건·경보 1건) 단위**로 다시 쟀다.
학습은 하지 않았고 모델·체크포인트·라벨·yaml·원본 데이터는 읽기만 했다.

> **판정 (§4): K=3 / N=5 + §9 창 끝 게이트 적용 — 사건 재현율 11/19 = 0.579, 빈 방·활동 오탐 0건 (0.0 FA/h).**
>
> **단, "FA/h < 1.0" 은 이 데이터로 확인되지 않는다.** 검증 빈 방 관측이 118.4 s 뿐이라 오탐 **1건 = 30.4 FA/h** 다.
> 0.0 은 "118.4 s 동안 0건" 이라는 뜻이다. 같은 조합에서 추론 시작을 160 ms 옮기면 빈 방 오탐이 1건(= 30.4 FA/h) 나온다.
> 다섯 오프셋 모두 0건인 조합은 K=4·K=5 뿐이다 (K=4 게이트 적용 재현율 9~10/19).
>
> **창 단위와 사건 단위는 크게 다르다.** 낙상 쪽은 창 재현율 0.480 → 사건 재현율 17/19 = 0.895 (집계 없음),
> 빈 방 쪽은 창 발화율 1.3% (200 ms 스트림 2.4%) → **425.7 FA/h** 다.
>
> K=3 에서 감지된 11건 중 **10건이 `1327_fall` 한 세션**이다 (`1340_fall` 1/4, `1345_fall_longlie` 0/4).

- 측정 코드: `scripts/eval_event_level.py`
- 추론 단위: `out/eval_event_stream.csv` (오프셋 0, 1763회 — 창 시각·라벨·귀속 낙상·게이트·점수)
- 낙상 단위: `out/eval_event_falls.csv` (19건 × 게이트 2 × 집계 6 감지 여부)
- 조건 요약: `out/eval_event_summary.csv` (오프셋 5 × 게이트 2 × 집계 6 = 60행)
- 체크포인트: `runs/m1_base_3node_20260916.pt` (epoch 5, strict=True) · 설정 `configs/m1_fall.yaml` · 라벨 `data/labels_split.csv`

### 0-2. 시스템 모사

| 항목 | 정의 |
|---|---|
| 추론 스트림 | 검증 세션마다 100 Hz 그리드에서 창 시작 0, 20, 40, … 프레임 = **200 ms 간격**. 추론 시각 = 창 마지막 슬롯 |
| 창 | `load_session` 그리드를 그대로 잘라 만든다. 오프셋 0 은 `make_windows`(stride 20, fall_stride 없음)와 **바이트 단위 동일**을 확인 (§1) |
| 낙상 j 의 양성 창 P_j | 데이터셋 규칙으로 라벨 1 인 창 중, 낙상 j 의 ±1000 ms 구간이 창 프레임의 50% 이상을 덮는 창. 단독으로 50% 를 못 넘으면 비율이 가장 큰 낙상에 귀속 (이번 측정에서 **0개**) |
| 발화 | 점수(sigmoid) ≥ 0.80. 게이트 적용 시 게이트를 통과한 추론만 |
| 게이트 | `M1_NODE_DROPOUT.md` §9 규칙 — 세 노드 모두 창 마지막 프레임이 실프레임일 때만 추론. **생략된 추론 = 발화 없음**, K-of-N 의 최근 5회에도 발화 아님으로 들어간다 |
| 경보 | 집계 없음: 발화 그대로 · K-of-N: 최근 5회(1 s) 중 발화 ≥ K. 세션 첫 4회는 있는 만큼만 센다 |
| **사건 감지** | P_j 의 추론 시각 중 경보가 켜진 때가 하나라도 있으면 감지. 집계 없음이면 요청 [1] "양성 창 중 하나라도 0.80 을 넘으면 감지" 와 같다. P_j 가 비면 미감지 (이번 측정에서 0건) |
| **오탐 건수** | 빈 방 / 활동 검증 세션에서 경보가 꺼짐→켜짐 으로 바뀐 횟수. 연속으로 켜진 구간은 1건. 켜져 있던 추론 수도 같이 낸다 |
| 관측 시간 · FA/h | 추론 횟수 × 200 ms · 오탐 건수 ÷ 관측 시간(h) |
| 대상 세션 | **검증 세션만**. 빈 방 `1356`·`1358`, 활동 `1350`. 학습 세션은 학습에 쓰였으므로 넣지 않았다 |

| **주 판정 A** | **K=3 / N=5, 게이트 적용** — 사건 재현율 **11/19 = 0.579** · 빈 방 0건 (0.0 FA/h) · 활동 0건 (0.0 FA/h) |
| 참고 B (빈 방만) | 같은 조합 — K=3 / N=5, 게이트 적용 |
| 동률 처리 | K=3 게이트 **미적용**도 재현율 11/19 · 오탐 0건으로 완전히 같다. 규칙(동률 → 게이트 적용)에 따라 적용 쪽을 골랐다 |

### ⚠️ FA/h 0.0 을 "FA/h < 1.0 확인" 으로 읽으면 안 된다

- 검증 빈 방 관측은 **118.4 s (0.03289 h)**, 활동은 **59.2 s (0.01644 h)** 다.
  이 관측 시간에서 FA/h 로 나올 수 있는 값은 빈 방 **0, 30.4, 60.8, …**, 활동 **0, 60.8, 121.6, …** 뿐이다.
  **"FA/h < 1.0" 은 "관측 중 0건" 과 같은 말**이다. 측정 눈금이 30.4 FA/h 단위라 0.0 과 1.0 FA/h 수준을 가려낼 해상도가 없다.
- 추론 시작 오프셋만 바꿔도 K=3 의 빈 방 오탐이 달라진다 (§6):

| 조합 | 오프셋 0 / 40 / 80 / 120 / 160 ms 빈 방 오탐 건수 | 사건 재현율 |

| K=3 게이트 미적용 | 0 / 0 / 0 / 0 / **2** | 11 / 13 / 11 / 12 / 10 |
| K=4 게이트 적용 | 0 / 0 / 0 / 0 / 0 | 9 / 9 / 9 / 9 / 10 |

| K=5 게이트 적용 | 0 / 0 / 0 / 0 / 0 | 6 / 6 / 8 / 6 / 6 |

  오프셋 160 ms 에서 K=3 은 빈 방 오탐 1건(게이트 적용) = 30.4 FA/h, 2건(미적용) = 60.8 FA/h 다.
  **다섯 오프셋 모두에서 빈 방 0건인 조합은 K=4·K=5 뿐**이다.
